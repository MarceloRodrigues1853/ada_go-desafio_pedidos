# Frontend do Sistema de Pedidos

Painel operacional desenvolvido com React, TypeScript e Vite.

## Configuração

```bash
cp .env.example .env
npm install
npm run dev
```

`VITE_API_URL` deve apontar para a API Go. O valor local padrão é
`http://localhost:8080`.

## Validação

```bash
npm run build
npm run lint
```
